🛠️Método de Construcción

🔴VERSIÓN 1: Reseteo y Fuente

PASO 1: Crea style.css y enlázalo en HTML

En el <head> de tu HTML, agrega:

<link rel="stylesheet" href="style.css">

Ahora copia esto en style.css:

/* VERSIÓN 1: RESETEO Y FUENTE */

* {
  box-sizing: border-box;
}

body {
  margin: 0;
  font-family: Arial, Helvetica, sans-serif;
  color: #1f2937;
  line-height: 1.6;
}

img {
  max-width: 100%;
  display: block;
}

🔴VERSIÓN 1: Resultado

✓ Qué pasó:

  • El texto se ve más pequeño y limpio
  • No hay espacios raros arriba (margin: 0)
  • Las imágenes no son enormes
  • Toda la página usa Arial
  • El espaciado entre líneas es mejor (line-height: 1.6)
Recuerda: Aún se ve fea, pero hemos removido los estilos "feos" del navegador. Ahora tenemos control total.

🔴VERSIÓN 1: ¿Qué significa cada línea?

❓ ¿Qué es "* { box-sizing: border-box; }"?
El asterisco (*) significa "TODO en la página". box-sizing: border-box hace que los bordes no "rompan" el tamaño de las cosas.
❓ ¿Qué es "margin: 0"?
Margin es el espacio AFUERA de un elemento. El navegador agrega margin por defecto. Nosotros lo quitamos para tener control total.
❓ ¿Qué es "font-family"?
La TIPOGRAFÍA (tipo de letra). Arial es simple y clara para empezar.
❓ ¿Qué es "line-height: 1.6"?
El espacio entre líneas de texto. 1.6 significa 60% más espacio. Hace el texto más legible.

🟠VERSIÓN 2: Colores Base

PASO 2: Agrégalo al final de style.css

Copia y pega esto (no reemplaces lo anterior):

/* VERSIÓN 2: COLORES BASE */

header {
  background-color: #0f172a;
  color: white;
}

nav {
  background-color: white;
  border-bottom: 1px solid #e5e7eb;
}

a {
  color: #1d4ed8;
}

footer {
  background-color: #020617;
  color: #cbd5e1;
}

🟠VERSIÓN 2: Resultado

✓ Qué cambió:

  • El HEADER es azul oscuro con texto blanco
  • El MENÚ es blanco con una línea gris abajo
  • Los ENLACES son azules
  • El FOOTER es negro con texto gris claro
  • La página empieza a parecer un sitio real
¡Mira la diferencia! Solo agregamos colores y ya se ve mucho mejor. CSS está haciendo magia.

🟠VERSIÓN 2: Entendiendo Selectores

Los selectores son cómo le dices a CSS QUÉ elemento estilizar:

header { ... } → Aplica estilos a la etiqueta <header>

nav { ... } → Aplica estilos a la etiqueta <nav>

a { ... } → Aplica estilos a TODOS los <a> (enlaces)

footer { ... } → Aplica estilos a la etiqueta <footer>

❓ ¿Mayúsculas o minúsculas?
SIEMPRE minúsculas en CSS. header funciona, Header NO funciona.
❓ ¿Qué es "border-bottom"?
Una línea en la parte INFERIOR. 1px = grosor, solid = tipo, #e5e7eb = color gris.

🟡VERSIÓN 3: Espaciado (Padding/Margin)

PASO 3: Agrégalo al final de style.css

El espaciado hace que la página "respire":

/* VERSIÓN 3: ESPACIADO */

.contenedor {
  width: min(1100px, 90%);
  margin: 0 auto;
}

header {
  padding: 70px 0;
}

section {
  padding: 60px 0;
}

nav {
  padding: 14px 0;
}

footer {
  padding: 25px 0;
}

🟡VERSIÓN 3: Resultado

✓ Qué cambió:

  • El contenido no toca los bordes de la ventana
  • Hay "aire" adentro de cada sección
  • Las secciones están separadas visualmente
  • La página no se ve apretada
  • ¡Se ve más profesional!
Principio de diseño: El espacio en blanco es importante. No es "desperdicio". Es lo que hace que una página sea agradable de leer.

🟡VERSIÓN 3: Padding vs Margin

PADDING (adentro)

Espacio DENTRO del elemento

padding: 70px 0;
70px arriba/abajo
0px izq/der

MARGIN (afuera)

Espacio AFUERA del elemento

margin: 0 auto;
0px arriba/abajo
auto izq/der (CENTRA)

❓ ¿Qué es "min(1100px, 90%)"?
"El menor entre 1100px y 90% de la ventana". En pantalla pequeña: 90%. En grande: máximo 1100px. Responsivo automático.

🟢VERSIÓN 4: Layout con Grid

PASO 4: Agrégalo al final de style.css

Grid organiza el contenido en columnas:

/* VERSIÓN 4: LAYOUT CON GRID */

.header-content {
  display: grid;
  grid-template-columns: 1.2fr 0.8fr;
  gap: 40px;
  align-items: center;
}

.menu-content {
  display: flex;
  justify-content: center;
  gap: 25px;
}

.tarjetas {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
  margin-top: 30px;
}

🟢VERSIÓN 4: Resultado

✓ Qué cambió:

  • El HEADER ahora tiene 2 columnas (texto + imagen)
  • El MENÚ está HORIZONTAL y centrado
  • Las TARJETAS están en 3 columnas
  • El contenido tiene estructura visual clara
  • ¡Es un verdadero LAYOUT de página web!
CSS Grid es lo que hace que las páginas web modernas funcionen. Google, Amazon, Netflix... todos usan Grid.

🟢VERSIÓN 4: Grid vs Flexbox

GRID
Organiza en TABLA (filas Y columnas)
Perfecto para layouts complejos
grid-template-columns: repeat(3, 1fr)
FLEXBOX
Organiza en LÍNEA (flexible en una dirección)
Perfecto para menús y botones
display: flex; justify-content: center;
❓ ¿Qué es "gap: 40px"?
Espacio ENTRE elementos. Con gap, no necesitas calcular márgenes complicados.
❓ ¿Qué es "repeat(3, 1fr)"?
Repite 3 veces una columna de 1 parte. 3 columnas IGUALES.

🔵VERSIÓN 5: Tarjetas y Cajas

PASO 5: Agrégalo al final de style.css

Hacemos que las tarjetas se vean como cajas 3D:

/* VERSIÓN 5: TARJETAS Y CAJAS */

.tarjeta, .caja-destacada {
  background-color: white;
  padding: 25px;
  border-radius: 18px;
  box-shadow: 0 10px 25px rgba(15,23,42,0.08);
}

.tarjeta h3, .caja-destacada h3 {
  margin-top: 0;
  color: #1d4ed8;
}

.enlaces a {
  background-color: white;
  color: #1d4ed8;
  padding: 12px 16px;
  border-radius: 12px;
  text-decoration: none;
  border: 1px solid #bfdbfe;
}

.enlaces a:hover {
  background-color: #dbeafe;
}

🔵VERSIÓN 5: Resultado

✓ Qué cambió:

  • Las tarjetas tienen SOMBRA (parecen flotar)
  • Las esquinas están redondeadas
  • El fondo es blanco y tienen padding
  • Los títulos son azules
  • Los enlaces parecen botones
  • ¡La página parece PROFESIONAL!
La sombra es la clave. Agrega profundidad y hace que los elementos "floten" sobre la página.

🔵VERSIÓN 5: Entendiendo box-shadow

box-shadow: 0 10px 25px rgba(15,23,42,0.08);
    ↑   ↑       ↑                        ↑
    H   V      Blur           Color
  • 0: Desplazamiento horizontal (0 = centrado)
  • 10px: Desplazamiento vertical (hacia abajo)
  • 25px: "Difuminado" de la sombra (más = más suave)
  • rgba(...): Color = negro, 0.08 = muy transparente
❓ ¿Qué es "border-radius: 18px"?
Redondea las esquinas. 18px = muy redondeado. 0px = cuadrado. 50% = círculo perfecto.

🟣VERSIÓN 6: Botones y Responsive

PASO 6: Agrégalo al final de style.css (FINAL)
/* VERSIÓN 6: BOTONES Y RESPONSIVE */

.boton {
  display: inline-block;
  background-color: #f97316;
  color: white;
  padding: 12px 22px;
  border-radius: 999px;
  text-decoration: none;
  font-weight: bold;
}

.boton:hover {
  background-color: #ea580c;
}

.menu {
  position: sticky;
  top: 0;
  z-index: 10;
}

@media (max-width: 768px) {
  .header-content, .tarjetas {
    grid-template-columns: 1fr;
  }
}

🟣VERSIÓN 6: Resultado FINAL

✓ Qué cambió:

  • Los botones son naranjas con esquinas muy redondeadas
  • Al pasar el ratón, se oscurecen (:hover)
  • El menú se queda arriba al bajar (sticky)
  • En celular: 1 columna. En escritorio: 2-3 columnas
  • ¡LA PÁGINA ESTÁ COMPLETA Y PROFESIONAL!

🟣VERSIÓN 6: Conceptos avanzados

❓ ¿Qué es ":hover"?
Estilos que se aplican cuando pasas el ratón. Hace la página INTERACTIVA.
❓ ¿Qué es "position: sticky"?
El menú se queda en la parte superior aunque bajes la página. Muy útil para navegación.
❓ ¿Qué es "z-index: 10"?
Define qué elemento está "arriba". Número más alto = más arriba. Asegura que el menú esté sobre el contenido.
❓ ¿Qué es "@media (max-width: 768px)"?
Estilos SOLO para pantallas menores de 768px (celulares). En móvil: 1 columna. En escritorio: 2-3 columnas. ¡Responsivo!

❓Preguntas de Verificación

1. ¿Cuál es la diferencia entre padding y margin?
Padding = espacio DENTRO. Margin = espacio AFUERA.
2. ¿Qué hace "display: grid"?
Crea un sistema de columnas. Los elementos se organizan en filas y columnas.
3. ¿Qué hace "background-color"?
Define el color de FONDO de un elemento.
4. ¿Qué hace ":hover"?
Aplica estilos cuando pasas el ratón sobre el elemento.
5. ¿Qué es un SELECTOR en CSS?
Lo que va ANTES de las llaves. Le dice a CSS QUÉ elemento estilizar. Ejemplo: header, .boton, #inicio
